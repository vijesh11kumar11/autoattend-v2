# AutoAttend AI — Asset Requirements

Place the following image files in this directory:

| File                    | Size        | Description                                                |
|-------------------------|-------------|------------------------------------------------------------|
| `icon.png`              | 1024×1024   | App icon (graduation cap on #1a237e blue background)       |
| `adaptive-icon.png`     | 1024×1024   | Android adaptive icon foreground                           |
| `splash.png`            | 1284×2778   | Splash screen (logo centered on white, bg set to #1a237e in app.json) |
| `favicon.png`           | 32×32       | Web favicon                                                |
| `notification-icon.png` | 96×96       | Android notification icon (white on transparent, monochrome) |

### Design Guidelines
- Primary color: `#1a237e` (deep indigo)
- Icon style: graduation cap / checkmark hybrid
- Notification icon: must be monochrome white-on-transparent (Android notification bar requirement)
